# Coco Latte

MVP web para la gestión de una cafetería. Incluye menú filtrable, roles de demostración, registro de ventas, administración de productos, estadísticas y calificaciones, todo persistente con `localStorage`.

## Ejecutar

Abre `index.html` en un navegador o usa la extensión **Live Server** de Visual Studio Code. No requiere instalación ni backend. Para reiniciar la demostración, borra los datos del sitio desde las herramientas del navegador (`localStorage`).

## Accesos

En `login.html`, los botones de demostración permiten entrar como Cliente, Trabajador o Administradora.
